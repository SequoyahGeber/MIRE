### Environmental traps written down (cost real time, not code bugs)

- **F-196 — an asset rebuild racing `agent godot`'s auto-import pass poisons the import cache.**
  8 station GLBs stayed unloadable for 40+ minutes of checks (16 ERROR lines per map check) while
  valid on disk; one explicit `agent godot --import` cleared everything. Mechanism and two fix
  shapes in the finding; until one lands, the workaround is in it too.
- **The sessions lock wedged transiently** under 5 concurrent sessions (empty `.holder` = "holder
  unknown", 10 s timeout) and failed 5 early battery runs; all clean on rerun. Adjacent to F-186
  (session-death claim cleanup), which was in flight during the audit.
- **Checks with non-standard invocations are un-runnable by a naive runner** — `seed_launch_arg`
  requires `-- --seed=204060517` (its own header says so), `multimesh_readback` is headless-only
  *by design* (it asserts the F-103 trap holds; windowed, it "fails" by succeeding), four need
  `--windowed`. This battery learned each by reading headers after a red. A one-line
  machine-readable convention (say `## RUN: --windowed` in the header) would make the next audit's
  runner exact; left as a suggestion, not filed — the cost is once per audit.

### Also closed in passing

## 2 · Performance — where it actually stands

The ask was "optimize as much as possible." The honest finding: **the CPU-side runtime has already
been through three deliberate optimization passes** (F-090 presets + probe, F-099 cheap-read seams,
F-105 cached autoload lookups), and it shows. Verified by reading every `_process`/
`_physics_process` in `autoload/`, `systems/`, `ui/`, `entities/`, `world/`:

- Every UI panel polls behind an accumulator; `crafting_service` turns its own processing off when
  idle; `vitals_hud`'s per-frame read is one static int compare, documented (F-099).
- Enemy AI: target rescan behind `RESCAN_INTERVAL_SEC`, one-hop pack alerts, distance-squared
  everywhere, per-tick attack-slot scan documented and bounded by live-enemy count. Fine at pack
  scale; the wave director caps populations.
- `MireGrid` ticks at 2 s intervals, delta-broadcasts changed cells only.
- The two systemic costs that remain are **render-side and already owned**: props LOD/batching and
  per-preset `mesh_lod_threshold` are F-144, in flight with its own instrument
  (`frame_cost_check`) during this audit. Nothing this audit could add without colliding with
  that claim.

Net new perf work from this audit: F-194 (136 engine-error prints per netted run were not free),
and the shim deletion (one fewer wrapped-Callable indirection per legacy console command — small,
but it also deleted the code that made it possible to *add* more).

What deliberately was **not** done: no micro-rewrites of working code for speculative wins, no
relitigating D-075 (per-call `FastNoiseLite` is thread-safety by decision, measured in D-080), and
no touching F-144's twelve claimed files.
